# Drive-Manager-for-DosBox
This program is a GUI wrapper for the mount and imgmount commands in DosBox.

This program is written using the DOS version of Visual Basic.

# Instructions:

Step 1: Install the DOS version of Visual Basic in DosBox.

Step 2: Create an empty directory. Then, create another empty directory named "drvmgr" inside the first directory.

Step 3: Copy the source code files (drvmgr.mak, drvlist.frm, errmsg.frm, and mountdrv.frm) to the "drvmgr" directory.

Step 4: Mount the directory containing the "drvmgr" directory as drive I: in DosBox.

Step 5: Load drvmgr.mak in the DOS version of Visual Basic.

After this process is complete, you can edit the source code using the DOS version of Visual Basic or compile it.

To compile it, select the "Make EXE File" from the "Run" menu.

To directly download the compiled EXE, go to the releases section to download it.
